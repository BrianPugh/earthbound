| 2-layer rippling battle BG (Frank's): only about 1 port frame in 4 matches an emu frame scanline for scanline. The per-scanline HOFS tables are bit-exact: for the same animation state (layer position, distortion speed) the port's table for each layer equals the original's `ANIMATED_BACKGROUND_LAYER_1_HDMA_BUFFER` on every line. Two things differ by history, not logic: with both layers distorting, `DISTORT_30FPS` recomputes layer 1 on even `FRAME_COUNTER` and layer 2 on odd, and the counter's parity against the animation state depends on earlier lag frames (the port's run had it the other way; shifting the port's counter by 1 made its tables match the emu's frame for frame). Also, the original rewrites the HDMA buffer during active display (no double buffer), so emu pictures mix tables of 2 frames in bands (the top ~15 lines and others), which no port frame has.
