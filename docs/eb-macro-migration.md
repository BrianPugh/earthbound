# Configurable Macro Audit & `EB_` Migration

Audit of all user/programmer-exposed *configurable* macros in the C port
(`src/`, `port/`). Configurable = overridable at build time via `-D…` or a CMake
`option()`/`target_compile_definitions` (the `#ifndef X / #define X default` and
external-`#ifdef` knobs). The convention is: **every configurable knob carries an
`EB_` prefix.** Backward compatibility is not preserved — the old spellings are
removed, not aliased.

## Migration table (rename these)

| Old name | New name | Default | Defined / overridden at | Purpose |
|---|---|---|---|---|
| `ENABLE_AUDIO` | `EB_ENABLE_AUDIO` | `ON` | `src/CMakeLists.txt` option | Build lakesnes SPC700/DSP audio |
| `ENABLE_VERIFY` | `EB_ENABLE_VERIFY` | `OFF` | `src/CMakeLists.txt` option | Side-by-side ROM verification |
| `ENABLE_DUAL_CORE_PPU` | `EB_ENABLE_DUAL_CORE_PPU` | `OFF` | `port/waveshare/pico-lcd-1.3/CMakeLists.txt` option | Split PPU render across RP2040 cores |
| `BATTLE_LETTERBOX_ENABLED` | `EB_BATTLE_LETTERBOX` | `1` | `src/game/battle.h` `#ifndef` | Black bars top/bottom in battle |
| `MAX_FRAME_SKIP` | `EB_MAX_FRAME_SKIP` | `0` | `src/game_main.c` `#ifndef` | Max consecutive skipped frames |
| `FAST_FORWARD_MULTIPLIER` | `EB_FAST_FORWARD_MULTIPLIER` | `3` | `src/core/types.h` `#ifndef` | Tab-key fast-forward speed |
| `WINDOW_SCALE` | `EB_WINDOW_SCALE` | `3` | `port/unix/platform/sdl2_video.c` `#ifndef` | Initial SDL window scale |
| `PLATFORM_HOST_PACED_FRAMESKIP` | `EB_HOST_PACED_FRAMESKIP` | undefined | port build define | Delegate frameskip to `platform_timer_should_render()` |
| `PPU_FORCE_SPEED_OPT` | `EB_PPU_FORCE_SPEED_OPT` | undefined | port build define | Force `-O3` on PPU hot path |
| `PPU_RAM_SECTION` | `EB_PPU_RAM_SECTION` | undefined | port build define | Place PPU hot funcs in fast RAM section |
| `PPU_LINEBUF_ATTR` | `EB_PPU_LINEBUF_ATTR` | empty | port build define | Route scanline buffers to fast memory (e.g. DTCM) |
| `PPU_BG_ROW_CACHE` | `EB_PPU_BG_ROW_CACHE` | `1` | `src/snes/ppu_render.c` `#ifndef` | BG row decode cache |
| `PPU_OBJ_BUCKET` | `EB_PPU_OBJ_BUCKET` | `1` | `src/snes/ppu_render.c` `#ifndef` | OBJ bucket sort optimization |
| `PPU_NUM_RENDER_CONTEXTS` | `EB_PPU_NUM_RENDER_CONTEXTS` | `1` | `src/snes/ppu.h` `#ifndef` | Independent render contexts (2 = dual-core) |
| `PPU_PROFILE` | `EB_PPU_PROFILE` | undefined | port build define | Per-section PPU timing instrumentation |

## Already compliant (no action)

`EB_VIEWPORT_WIDTH`, `EB_VIEWPORT_HEIGHT`, `EB_PIXEL_RGB565`,
`EB_B_OPENS_MAIN_MENU`, `EB_NORELOC_REQUIRED`, `EB_EMBEDDED`,
`EB_HAVE_SAVESTATE_BACKEND`.

## Deliberately NOT renamed

| Macro | Reason |
|---|---|
| `VRAM_SIZE` (`constants.h`, guarded) | Hardware-fixed SNES size (`0x10000`); the `#ifndef` is incidental, not a tunable knob |
| `ENABLE_ASAN`, `ENABLE_UBSAN` | Standard CMake sanitizer-toggle convention; pure build-tool options, never reach C source as logic |
| `EB_VIEWPORT_PAD_*`, `EB_VIEWPORT_CENTER_*`, `LINE_BUF_WIDTH`, `TARGET_FPS` | Derived/fixed, not overridable |
| `ASSET_*_BIN_DATA`, `*_INCLUDE_NAMES`, `EBASSET_TABLE_ATTR` | Auto-generated by the asset/embed registry, not hand-set |
| `EB_CHAR_*`, `EB_TRUE/FALSE/NULL`, `EB_STRING`, `EB_PLAYER`, … | Already-prefixed plain constants/helpers, not build knobs |
